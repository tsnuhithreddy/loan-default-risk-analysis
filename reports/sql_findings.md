# SQL Business Intelligence Findings — FinTrust Lending Co.

**Analyst:** Telukala Snuhith Reddy
**Database:** `fintrust_lending` (MySQL 8.0) | 32,416 records post-cleaning
**Methodology Note:** These findings summarize descriptive metrics and aggregations derived from the 28 SQL business intelligence queries. They describe historical, in-sample associations within the portfolio rather than causal relationships or out-of-sample predictive performance.

---

### Finding 1 — Observed Default Rates Escalate Sharply Across Loan Grades

SQL analysis confirms a strong, monotonic increase in observed default rates across loan grades:

* **Grade A:** 9.96% default rate (n = 10,703; 1,066 defaults)
* **Grade B:** 16.32% default rate (n = 10,387; 1,695 defaults)
* **Grade C:** 20.75% default rate (n = 6,438; 1,336 defaults)
* **Grade D:** 59.06% default rate (n = 3,620; 2,138 defaults)
* **Grade E:** 64.49% default rate (n = 963; 621 defaults)
* **Grade F:** 70.54% default rate (n = 241; 170 defaults)
* **Grade G:** 98.44% default rate (n = 64; 63 defaults)

**Business Implication:** Loan grade provides strong empirical risk differentiation within the historical portfolio. The sharp increase from Grade C to Grade D indicates a substantial concentration of observed default risk in the lower-rated segments. Grades E–G warrant particularly close exposure monitoring because defaulted principal exposure can substantially exceed first-year interest generated by performing loans.

### Finding 2 — Prior Default History Shows a Strong Association with Default Risk

Query 15 shows that borrowers with a historical default on file defaulted at **37.87%** (2,170 defaults / 5,730 loans), compared with **18.43%** (4,919 defaults / 26,686 loans) among borrowers without a recorded prior default. This represents an observed **2.05× risk ratio**.

**Business Implication:** Prior bureau-reported default history is a strong bivariate categorical indicator of elevated observed default risk in this portfolio. Applications with `cb_person_default_on_file = 'Y'` could therefore be considered for enhanced underwriting review, subject to validation through out-of-sample testing and applicable lending-policy requirements.

### Finding 3 — Three Loan Intents Exceed the Portfolio Average Default Rate

Query 3 identifies three loan purposes with observed default rates above the portfolio average of **21.87%**:

* **Debt Consolidation:** 28.68% (1,488 defaults / 5,189 loans)
* **Medical:** 26.76% (1,617 defaults / 6,042 loans)
* **Home Improvement:** 26.15% (940 defaults / 3,594 loans)

**Business Implication:** Debt consolidation, medical, and home-improvement loans exhibit elevated observed default rates relative to the overall portfolio. These segments could be evaluated for additional affordability checks, income verification, or tighter leverage thresholds. Any proposed underwriting restrictions should be validated against profitability, approval rates, and out-of-sample performance before implementation.

### Finding 4 — Loan-to-Income Ratio Shows a Sharp Risk Escalation Above 35%

Queries 8 and 27 evaluate borrower leverage using `loan_percent_income`, expressed as the proportion of annual income represented by the loan amount:

* **Low (<20%):** 13.43% default rate (2,868 defaults / 21,363 loans)
* **Medium (20–34%):** 29.05% default rate (2,508 defaults / 8,634 loans)
* **High (35–49%):** 69.87% default rate (1,456 defaults / 2,084 loans)
* **Critical (≥50%):** 76.72% default rate (257 defaults / 335 loans)

**Business Implication:** Observed default rates increase sharply once the loan-to-income ratio reaches 35%, with the 35–49% tier exhibiting a substantially higher default rate than the lower-leverage groups. This empirical step-change supports evaluating **35% as a candidate threshold for enhanced underwriting review**, subject to validation using out-of-sample data.

### Finding 5 — Default Rates Are Higher at Both Ends of the Observed Age Distribution

Query 6 shows that observed default rates are higher among the youngest and oldest borrower groups than among the middle-age groups:

* **Young Borrowers (<25):** 23.34% default rate (n = 12,222; 2,853 defaults)
* **Early Career (25–35):** 20.98% default rate (n = 16,734; 3,511 defaults)
* **Mid Career (36–50):** 20.55% default rate (n = 3,172; 652 defaults)
* **Senior Borrowers (>50):** 25.35% default rate (n = 288; 73 defaults)

**Business Implication:** The historical data shows higher observed default rates at both age extremes relative to the middle-age groups. This suggests that borrower life stage may be relevant to risk segmentation, although age should be evaluated carefully alongside financial and affordability variables rather than treated as a standalone underwriting criterion.

### Finding 6 — Home Ownership Status is Strongly Associated with Default Outcomes

Queries 4 and 24 show substantial differences in observed default rates across housing-tenure categories:

* **RENT:** 31.61% default rate (n = 16,378; 5,177 defaults)
* **OTHER:** 31.13% default rate (n = 106; 33 defaults)
* **MORTGAGE:** 12.62% default rate (n = 13,369; 1,687 defaults)
* **OWN:** 7.49% default rate (n = 2,563; 192 defaults)

**Business Implication:** Borrowers reporting RENT or OTHER housing status exhibit substantially higher observed default rates than borrowers reporting MORTGAGE or OWN. Housing tenure may therefore serve as a useful segmentation variable when combined with affordability and credit-risk indicators. The very small `OTHER` segment should be interpreted cautiously because its estimate is based on only 106 loans.

### Finding 7 — Simplified Financial Exposure Analysis Shows Negative Net Positions Across All Grades

Query 20 compares first-year simple interest calculated on non-defaulted loans against principal exposure from defaulted loans. Under this simplified proxy, every loan grade produces a negative net position:

* **Grade A:** **-$4.18M** ($5.99M interest vs. $10.17M defaulted principal)
* **Grade B:** **-$9.70M** ($9.33M interest vs. $19.03M defaulted principal)
* **Grade C:** **-$7.41M** ($6.16M interest vs. $13.57M defaulted principal)
* **Grade D:** **-$20.23M** ($2.55M interest vs. $22.78M defaulted principal)
* **Grade E:** **-$7.04M** ($0.79M interest vs. $7.83M defaulted principal)
* **Grade F:** **-$2.30M** ($0.20M interest vs. $2.50M defaulted principal)
* **Grade G:** **-$1.10M** ($0.000307M interest vs. $1.10M defaulted principal)

**Business Implication:** Under this simplified first-year exposure proxy, first-year interest generated by performing loans does not offset defaulted principal exposure in any grade. Grade D represents the largest absolute defaulted-principal exposure and therefore the largest negative net position. This analysis is **not an accounting profit calculation**: it excludes recoveries, operating costs, funding costs, fees, loan tenure, and other components of realized lending economics.

### Finding 8 — Composite Risk Flag Captures a Distinct High-Risk Cohort

Query 10 evaluates a composite analytical risk flag based on the presence of at least one of the following conditions: **Grade E/F/G**, **loan-to-income ratio above 40%**, or **prior default on file**:

* **High-Risk Cohort:** 44.45% default rate (n = 7,228; 3,213 defaults)
* **Normal Cohort:** 15.39% default rate (n = 25,188; 3,876 defaults)

The flagged cohort represents approximately **22.3% of the portfolio** while accounting for approximately **45.3% of observed defaults**.

**Business Implication:** The composite flag effectively separates a historically higher-risk segment from the remainder of the portfolio. It could be used as an analytical prioritization tool for enhanced review, but automated underwriting deployment would require temporal/out-of-sample validation, threshold sensitivity analysis, calibration testing, and appropriate fairness assessment.

### Finding 9 — Observed Grade Performance Diverges from the Reference Risk Matrix

Query 13 compares observed portfolio performance against the simulated `risk_scoring_matrix` by mapping grades into broader risk tiers:

* **Low Risk:** Grades A and B
* **Medium Risk:** Grades C and D
* **High Risk:** Grades E and F
* **Critical Risk:** Grade G

The observed default rates for **Grade C (20.75%)** and **Grade D (59.06%)** indicate that the middle-grade segment contains substantially different risk levels, with Grade D exhibiting a particularly large increase in observed defaults relative to Grade C.

**Business Implication:** The substantial divergence between Grades C and D suggests that treating both grades as a single medium-risk category may conceal meaningful risk heterogeneity. The reference scoring framework should therefore be recalibrated or further segmented using observed portfolio performance before being used for operational risk decisions.

### Finding 10 — Income Quartiles Show a Strong Inverse Association with Default Rate

Query 23 uses SQL `NTILE(4)` to divide borrowers into four approximately equal-sized income groups:

* **Quartile 1 ($4,000–$38,500):** 39.75% default rate (n = 8,104; 3,221 defaults)
* **Quartile 2 ($38,556–$55,000):** 21.41% default rate (n = 8,104; 1,735 defaults)
* **Quartile 3 ($55,000–$79,200):** 17.14% default rate (n = 8,104; 1,389 defaults)
* **Quartile 4 ($79,272–$140,232):** 9.13% default rate (n = 8,104; 740 defaults)

**Business Implication:** Default rates decline consistently as borrower income increases, with the lowest-income quartile exhibiting more than four times the observed default rate of the highest-income quartile. Lower-income applicants may therefore warrant enhanced affordability and income-verification checks, subject to applicable lending and fair-lending requirements.
