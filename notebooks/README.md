# Notebooks

`Loan_default_risk_analysis.ipynb` — the full analysis notebook, built and run in Google Colab. Covers data cleaning and validation, exploratory data analysis (10 charts), statistical validation (chi-square test, two-proportion z-tests, confidence intervals), and financial impact analysis.

To run: open in Google Colab, upload `data/raw/credit_risk_dataset.csv` when prompted, then `Runtime → Run all`.
